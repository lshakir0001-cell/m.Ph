# تطبيق الصيدلية الصغيرة | Mini Pharmacy (APP)

تطبيق ويب (PWA) للثلاجة الذكية. ينفتح من المتصفح، وتقدرون تضيفونه للشاشة الرئيسية في الجوال ويشتغل مثل أي تطبيق.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | التطبيق كامل: الشاشات والتصميم والكود |
| `manifest.webmanifest` | اسم التطبيق وأيقونته وألوانه لما ينضاف للشاشة الرئيسية |
| `sw.js` | يخلي التطبيق يفتح حتى بدون نت |
| `icons/` | أيقونات التطبيق |

ملفات Python الموجودة في المجلد (`Login.py` و`Main.py` و`reminders.py`) فاضية وما يستخدمها التطبيق.

## الشاشات

- **الرئيسية:** حرارة الثلاجة، حالة القفل وزر فتحه برمز PIN، والمنتجات اللي قرّب تنتهي.
- **المخزون:** أدوية وسكن كير، بحث، وألوان الصلاحية (أخضر سليم، أصفر قرّب، أحمر منتهي)، وتعديل الكمية.
- **إضافة:** مسح الكود بالكاميرا. كود DataMatrix اللي على علب الأدوية يعبّي تاريخ الانتهاء ورقم التشغيلة تلقائيًا.
- **التنبيهات:** المنتجات المنتهية واللي قرّب تنتهي، وسجل فتح وقفل الثلاجة.
- **الإعدادات:** اللغة (عربي وإنجليزي)، رمز القفل، نطاق الحرارة، مواعيد التنبيه، والقفل التلقائي.

## وش باقي

- **الثلاجة للحين محاكاة:** الحرارة والقفل ما يصيرون حقيقيين إلا لما نربط ESP32.
- **البيانات تنحفظ في كل جوال لحاله:** عشان يشوف الفريق كله نفس المخزون، نحتاج قاعدة بيانات أونلاين، مثل Firebase.
- **البيانات الموجودة تجريبية:** المنتجات والمستخدمين للعرض بس. تقدرون ترجعونها من الإعدادات.
- **رمز القفل التجريبي:** `1234`.

## النشر

أي تعديل يترفع على مجلد `APP` في فرع `main` ينشره GitHub Pages تلقائيًا، عن طريق الملف `.github/workflows/pages.yml`.

أول مرة بس، لازم صاحب الريبو يفعّل GitHub Pages: تروح **Settings** ثم **Pages**، ومن خانة **Source** تختار **GitHub Actions**.

بعدها التطبيق يكون على هالرابط:
`https://lshakir0001-cell.github.io/m.Ph/`

## تجربته على الكمبيوتر

```bash
cd APP
python3 -m http.server 8000
```

افتحوا `http://localhost:8000`. الكاميرا تحتاج رابط `https` أو `localhost`.
